如果只看边数，正七边形显然比正十七边形简单。可是在只允许无刻度直尺和圆规的规则里，结果恰好相反：正十七边形能够精确画出，正七边形却不能。

这里说的“精确”，不是把角度量到足够接近，而是每一个顶点都必须由有限次直线、圆和交点得到。我们真正要回答的是：七边形究竟卡在哪一步，十七边形又多了什么可以执行的结构？

先把正多边形缩成一个局部任务。在单位圆上固定右端的起点，再找上半圆里的相邻顶点。把这个顶点记成 P，它的横坐标记成 x。

为什么只盯住横坐标就够？因为 P 在单位圆上，所以纵坐标的平方等于一减 x 的平方；又因为我们已经选定上半圆，纵坐标取正根。只要精确构造出 x，过 x 作垂线与圆相交，顶点 P 就被唯一确定了。

于是问题变成：直尺和圆规能够制造哪些精确长度？已有长度需要拼接时，圆规可以把一段长度搬到数轴上，于是得到加法和减法。

长度需要按比例缩放时，过对应端点作平行线，相似三角形会保持同一个比例，于是乘法和除法也能变成线段。

需要平方根时，把半圆的直径分成长度一和长度 a。分点处的垂线高度记成 h，相似三角形给出 h 的平方等于一乘 a，所以这条高度正好是根号 a。

这些不只是几个方便的例子，它们同时给出了尺规的边界。两条直线联立，只需要解一次方程；直线与圆联立，或者两个圆联立，消去一个坐标以后，剩下的最高也只是二次方程。二次方程的求根公式又只包含加减乘除和平方根。换句话说，每得到一个新交点，相对于此前已经知道的长度，最多增加一次平方根。

为了把这条边界说得更具体，我们给一个数标上“最简方程次数”。正式名称是最小多项式的次数。一个数可以满足很多方程，我们只看有理数系数中次数最低、而且不能继续拆开的那个。

根号二的最简方程是 x 的平方减二等于零，次数是二。再套一层根号，比如根号下一加根号二，消去内层根号后会得到一个四次方程。这里要用一个基础的代数事实：每增加一次二次求解，当前这层相对上一层的次数只能乘一或乘二；连续若干层以后，总次数一定是二的幂。目标数的最简方程次数必须整除这个总次数，所以也只能是一、二、四、八这类二的幂。

这是一道必要门槛，不是充分条件。次数是三，一定过不了尺规这一关；次数是八，却不能只凭“八是二的幂”就宣布成功，还要真的把方程拆成连续的二次方程。

现在先看正七边形。为了让圆周上的关系容易计算，记 c 下标 k 等于二乘以 cosine，括号里是七分之二 k 个圆周率。目标横坐标的两倍，就是字母 u 等于 c 下标一。

从圆心分别向七个顶点画箭头。因为七支箭头绕圆心完全对称，它们相加正好抵消为零。右端起点的横向长度是一；其余六个顶点上下两两对称，每一对的竖直分量抵消，横向投影之和分别是 c 一、c 二和 c 三。因此，一加 c 一，加 c 二，再加 c 三，等于零。

接下来只需要一个普通的积化和差公式。c 下标 i 乘 c 下标 j，等于 c 下标 i 加 j，再加 c 下标 i 减 j；下标绕七循环，正负下标表示同一个 cosine 数值。

把 i 和 j 都取一，得到 u 的平方等于 c 二加 c 零；而 c 零就是二乘以 cosine 零，等于二，所以 u 的平方等于 c 二加二。再乘一次 u：u 乘 c 二等于 c 三加 c 一，再加上原来的二 u，合起来就是 u 的三次方等于 c 三加三 u。

所以 c 二等于 u 的平方减二，c 三等于 u 的三次方减三 u。把它们代回刚才的圆周总和，逐项合并，得到 u 的三次方，加 u 的平方，减二 u，再减一，等于零。

这个三次方程能不能偷偷拆成一次方程和二次方程？如果可以，它就必须有一个有理数根。把这个有理数写成最简分数：分母必须整除首项系数一，分子必须整除常数项负一，所以可能的有理数根只有一和负一。

把一代进去，结果是负一；把负一代进去，结果是一。两个都不是零。因此这个三次式在有理数范围内确实拆不开，u 的最简方程次数就是三。

而尺规只能把一次和二次求解一层层接起来，得到的次数只能是二的幂。三不在这条链上，所以正七边形的第一个顶点无法由古典尺规精确构造。这才是七边形失败的具体位置。

再看十七边形。先纠正一个很容易产生的误会：十七减一等于十六，而十六是二的幂，这件事本身并不能证明十七边形可构造。九减一等于八，但正九边形不可构造；十五减一等于十四，正十五边形反而可以。

十六真正告诉我们的，只是除去右端已经固定的顶点以后，还有十六个顶点需要处理。把关于横轴对称的两个顶点配成一对，它们的竖直分量抵消，只留下横向投影之和。十六个顶点就这样配成八对。仍然记 c 下标 k 等于二乘以 cosine，括号里是十七分之二 k 个圆周率，k 从一到八。目标是 c 一。

关键不是“八可以随便二分”，而是找到一种分组，使每次分开后的两组都有可以算出的和与积。假如两个数的和是 s、积是 p，那么它们正好是方程 t 的平方，减 s t，再加 p，等于零的两个根。求根公式是 s 加减根号下 s 的平方减四 p，再除以二，只用到了尺规已经会做的四则运算和开平方。这就是“算出和与积”和“真的能用尺规分开两组”之间的桥。

第一层，把 c 一、c 二、c 四、c 八的和记成 A，把 c 三、c 五、c 六、c 七的和记成 B。这组下标不是随便挑的。把下标不断乘二，并把 k 和十七减 k 看成同一对：一、二、四、八会绕回一；从三出发，则会走过三、六、五、七，再绕回三。八个数自然分成了两个不会混在一起的循环。

从圆心指向十七个顶点的箭头相加也等于零。右端起点贡献一个一，其余八对顶点的横向投影之和就是 A 加 B，所以一加 A 加 B 等于零，也就是 A 加 B 等于负一。再用刚才的积化和差公式展开 A 乘 B，十六个乘积会变成三十二个 c 项；整理以后，c 一到 c 八恰好各出现四次。因此 A 乘 B 等于四倍的 c 一到 c 八之和，也就是负四。

和是负一，积是负四，所以 A 和 B 是二次方程 t 的平方，加 t，再减四，等于零的两个根。求根得到负一加减根号十七，再除以二。两个根都能由尺规得到，所以这里不需要靠猜测挑出一个、丢掉另一个；把两根都保留，A 和 B 就都已进入可用的长度清单。

第二层，把 A 再拆成 C 等于 c 一加 c 四，以及 D 等于 c 二加 c 八；把 B 拆成 E 等于 c 三加 c 五，以及 F 等于 c 六加 c 七。它们的和已经知道：C 加 D 等于 A，E 加 F 等于 B。

它们的积也可以直接核对。展开 C 乘 D，四个乘积经过积化和差以后，c 一到 c 八恰好各出现一次，所以 C 乘 D 等于负一。E 乘 F 的结果完全相同，也等于负一。

因此 C 和 D 是 t 的平方，减 A t，再减一，等于零的两个根；E 和 F 是 t 的平方，减 B t，再减一，等于零的两个根。第二层仍然只需要解二次方程。

最后一层，我们已经知道 C 等于 c 一加 c 四。再用一次积化和差，c 一乘 c 四等于 c 五加 c 三，右边正好就是已经得到的 E。

所以 c 一和 c 四是 t 的平方，减 C t，再加 E，等于零的两个根。第三层二次求解完成。因为从零到一个圆周率之间，cosine 会随角度增大而减小，较大的那个根就是 c 一，也就是二乘以 cosine，括号里是十七分之二个圆周率。

现在回到几何。第一层方程给出 A 和 B；第二层方程用 A、B 给出 C 和 E；第三层方程再用 C、E 给出 c 一。每一层都把已知的和与积代入同一个求根公式，只使用前面已经实际演示过的加减、乘除和平方根。最后把 c 一除以二，就得到第一个顶点的横坐标 x。

在单位圆的横轴上取出长度 x，过端点作垂线，与上半圆相交，得到第一个未知顶点 P。连接 P 和已经固定的起点，这条弦就是正十七边形的一条精确边长。

把圆规张到这条弦长，沿圆周依次复制。中间步骤可以加速，但圆规开口始终不变；最后一个交点回到起点，十七个顶点精确闭合。

把今天的两个具体案例推广开来，就是高斯—旺策尔判据：边数 n 必须等于二的某次幂，乘上一些互不重复的费马素数。所谓费马素数，就是二的某个次方再加一，其中这个指数本身还得是二的幂，而且最后的结果必须是素数。例如指数取一、二、四、八和十六，就得到三、五、十七、二百五十七和六万五千五百三十七；是否还有更多，目前仍不知道。

二的幂为什么出现并不神秘：一个正多边形已经能画以后，把每个圆心角平分，就能把边数翻倍。至于一般情况下为什么奇素数必须来自这张名单、而且不能重复，完整证明还需要更多代数。这里把它明确标成推广定理，不用它替代七边形和十七边形的具体推理。

对七和十七，我们已经看到了真正的分界：七边形的坐标被一个拆不开的三次方程挡住；十七边形的坐标则被高斯明确拆成了三层二次求解。难度不由边数大小决定，而由方程能不能一步步降到尺规允许的二次求解决定。
