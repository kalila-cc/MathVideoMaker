# 原神抽卡概率 v1 旁白审校

## Verdict

`Ready for TTS`

本轮用户要求先看无音轨低清预览，因此只完成放行审校，不生成TTS或SRT。

## 已解决的阻塞问题

- 开头已限定为“角色活动祈愿”，不把规则泛化到武器池、常驻池或其他祈愿。
- 固定 `0.6%` 明确标成没有保底的假模型，只用于建立对照。
- “第50抽概率”已说明三种问法的统计总数不同：第一问只看已经连续49抽没出五星的人，后两问从最初全部玩家里统计。
- 旁白保留 `UP`、保底、软保底、大保底、出金和歪等玩家熟悉的术语；首次用“当期UP角色”给出语境。
- 旁白保留“独立试验”“条件概率”“累计概率”“综合概率”和“分母”，并在同一句里指明它们对应的具体事件。
- 捕获明光不描述成“先判定非UP，再被粉光改写”的官方内部顺序，只说触发后本次五星就是当期角色。
- `0.018%` 与 `55%` 已分别说明统计范围，并明确不能直接相除，也不能把55%当成下一抽直接出当期角色的概率。
- 连续保护规则已写成“先歪、再拿大保底”重复三轮；没有写成连续多个五星全歪，也没有写成下一次单抽必出。
- 未使用社区流传的逐抽软保底公式或捕获明光逐阶段概率表。

## 口语与术语结果

- `社区拟合的逐抽曲线` 直接保留，因为“拟合”正好说明它来自数据估计，不是官方公布。
- `条件概率` 先说“只看已经走到这一抽的人”，然后立即命名；`累计概率` 与“到第50抽为止至少一次”绑定。
- `分母` 比“拿来当总数的人”更短也更准确，改回标准数学名词。
- 不为展示“口语化”而改写清晰的玩家术语或标准数学名词。
- 删除了“画面中间只能标问号”等制作备注式旁白。

## 公式朗读

- `0.994^90` 只在屏幕显示，旁白直接说“九十抽以后仍有大约百分之五十八的人一次五星都没见到”。
- `0.994^49×0.006` 与 `1-0.994^50` 只在屏幕显示；旁白只读结果和事件含义。
- 数字百分比已写成中文自然读法，例如“百分之零点零一八”。

## 多音字检查

- 未使用孤立的“量”“行”“重”等高风险词承担关键数学含义。
- “分母”放在“三个问题的分母不同”和“两个数字的分母不同”两个完整语境中，含义明确。
- “重新计算”没有进入旁白；使用“从头开始”或直接说明五星后计数归零。
- `UP` 需在正式TTS时试听字母读法；如果音色把它读成英文单词，用发音别名解决，不因此从文案中删掉术语。

## 节奏

- 当前旁白共9段，对应7个Scene；捕获明光Scene承接相邻两段。
- 低清预览目标时长约279秒。正式生成TTS后仍需按实测音频重新校准Scene内部节拍。
