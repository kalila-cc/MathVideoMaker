- 审校对象：`audio/gacha_pity_probability_v2_narration.txt`
- 结论：通过，可进入无音轨字幕预览制作

## 结构检查

- 开场在第一段直接给出 `0.6% / 1.6% / 90抽必出` 的矛盾感，并承诺画出三条曲线。
- 条件概率、PMF、CDF 按“分母不同 → 一般公式 → 固定模型数值 → 硬保底改形状”的顺序展开，观众不需要预先学过分布函数。
- `1.435%` 对照紧接硬保底曲线，用来回答“为何能知道有额外抬升”；三条示意解随后回答“为何仍不知道具体曲线”。
- UP 身份、双峰卷积和捕获明光放在五星等待之后，避免在定义 `T` 前混入第二层状态。
- 结尾重新对应条件概率、PMF、CDF与三项公开数字，能够回收开场问题。

## 语言检查

- 保留 UP、出金、歪、软保底、硬保底、大保底、捕获明光等游戏常用术语。
- 保留条件概率、PMF、CDF、分母、期望、卷积等标准数学名词；首次出现时均紧接具体解释。
- 句子以主动表达和短分句为主，没有使用“综上所述”“由此可见”等制作腔。
- 已把“软保底确实有统计现象”收窄为“玩家记录里常能看到后段出金更集中的统计现象”，避免把社区经验直接写成官方机制。
- 已把捕获明光 `55%` 的分母补全为“当前不是大保底、而且已经出了五星的情况”，避免被误读成单抽出当期 UP 的概率。

## 数学与口播风险

- 固定 `0.6%` 模型中，PMF 单调下降；旁白没有沿用桌面笔记中“先升后降”的错误描述。
- `0.994^89≈58.53%` 表示走到第 90 抽门前的人；`0.994^90≈58.18%` 表示抽完 90 次仍没出的人。文案分场使用，未混淆。
- `1/E[T]` 的解释限定在“把一次五星到下一次五星看成一轮”的长期口径，和综合概率的分母一致。
- 三条候选曲线只称“数学示意解”，不出现第 74 抽或每抽加 6 个百分点的社区拟合数字。
- 双峰段明确暂不计捕获明光，只讲基础 `50/50 + 歪后保证` 下的混合与卷积。

## 后续 TTS 注意项

本轮不生成音轨。后续制作正式配音时需试听以下读法：

- `q 下标 n`：建议在 TTS 输入中拆成“q，下标 n”。
- `PMF / CDF`：逐字母读，不自动译成英文单词。
- `0.994^89`、乘积号与卷积公式：只留在屏幕，不让 TTS 逐符号朗读。
- “概率质量函数”“累计分布函数”“卷积”首次出现处保留稍长停顿。
