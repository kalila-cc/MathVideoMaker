# 原神抽卡概率 v4 信息时序审查

## 结论

- Verdict：`Ready for silent captioned review`
- 17个场景按“教学模型 → 三种概率图 → 公开数字的边界 → 社区样本与模型 → UP身份层 → 捕获明光 → 总结”推进，没有在观众认识概念前引用其结论。

## 关键时序

- `q(n)`先用“仍在等待的人”解释，再引出PMF“首金分布”和CDF“累计出金率”；三条曲线各自用大图讲完后才缩成2×2复用。
- Paimon柱状图首次出现时先说明它是上传五星落点占比；随后才在右栏通过更换分母估计条件概率，避免把柱高误认成`q(n)`。
- Cgg虚线在Paimon样本之后出现，并明确来自另一批2021社区样本；Paimon上传样本、Cgg模型与官方90抽规则始终分开标注。
- `50/50`首次出现时同屏写为`50/50（五五开）`，并同时显示“无大保底时，当期UP 50% / 常驻五星 50%”；歪后下一颗五星保证UP随后定义为大保底。
- 捕获明光直到专门场景才首次命名并立即定义。此前双峰只使用已经讲过的五五开和大保底，并标明未计捕获明光。
- 捕获明光的`0.018%`与`55%`分开给出分母；`55%`还注明合并不同历史状态，不被解释成固定单抽UP率。
- 三轮历史用三张“非UP → 保证UP”卡正面展示，共6颗五星；没有提前引入中间阶段概率，也没有把未公开状态画成完整曲线。
- 结尾明确回扣两层规则：第一层是“什么时候出五星”，第二层是“五星是否为当期UP”，并再次显示`50/50（五五开）`、大保底和捕获明光。

## 仍需保留的边界提示

- Paimon数据来自自选上传记录，可能存在历史缺失、左截断与未完成等待；风险集条件概率是带假设的样本估计。
- Cgg曲线是另一批社区样本的拟合，不是对Paimon柱子的重新拟合，也不是官方公开的逐抽公式。
- 五五开与大保底双峰是简化模型下的UP等待分布，不是官方公布的个人精确概率。
