# 原神抽卡概率视频设计记录

## v1 目标

- 先交付低清、无音轨、带关键屏幕文字的完整预览。
- 旁白稿先完成并经过口语感、数学口径与信息顺序检查；本轮不生成TTS或SRT。
- 视频使用原创抽卡卡片、粒子和状态图，不复刻游戏角色、字体、祈愿动画或界面。

## v1 审阅反馈：术语保留

- 问题：前一轮“口语化”审校曾把避免 `UP` 当成优点，并把一些简洁的数学名词改写成长句。
- 改进规则：玩家已经熟悉的游戏术语和常见数学名词直接保留，首次出现时用具体事件或画面解释；只删除冷僻、不参与主线或真的会造成理解负担的词。
- 本轮影响：已更新旁白和大纲的语言规范；现有无音轨预览的屏幕本来就保留了 `UP`、保底、分母等词，因此无需重新渲染。

## 核心视觉

- 用“一万名玩家穿过抽卡闸门”统一表示三种概率：
  - 门的宽度：已经走到这一抽的人里，本抽出金的比例。
  - 当前门截下的粒子：正好在这一抽首次出金。
  - 已经离开的全部粒子：到这一抽为止至少出过一次。
- 第90道门完全打开，表示硬保底改变的是规则，不是运气自动回升。
- 进入UP判定后改用两层路径：先得到五星，再判断五星身份。捕获明光只出现在第二层。

## 官方与教学模型边界

- `p=0.006` 的几何分布只作为“没有保底”的教学对照。
- 官方没有公开逐抽概率曲线；中间抽数用问号门表示未知，不重画用户现有的社区拟合曲线。
- 捕获明光只显示官方明确的0.018%、综合55%和三轮后必触发，不画逐阶段概率表。
- 根目录现有四张 `genshin_up_*.png` 属于用户未跟踪文件，保留原位、不覆盖、不移动。

## 视觉系统

- 沿用项目深色背景与浅网格：背景 `#07111F`；网格 `#8FA8D8`、线宽1.6、透明度0.155、间距0.48。
- 中文使用 `assets/fonts/SmileySans-Oblique.ttf`；公式使用 `MathTex`。
- 主要颜色：五星金 `#F6B73C`、基础概率蓝 `#7DD3FC`、累计概率青 `#5EEAD4`、捕获明光粉 `#FF5C9A`、非UP灰 `#7C8798`。
- 480p预览也要读得清；同屏卡片超过三张时，优先分步替换，不压小字号。

## 峰值画面检查

- `ThreeNumbersHook`：三张数字卡和“五星什么时候来 / 这颗五星是谁”两层问题同时出现，捕获明光细节暂不出现。
- `ConstantChanceCorridor`：90道门压缩视图、58.2%幸存比例和公式同时出现。
- `ThreeQuestionsAtFifty`：三张完整问题卡同屏，并各自写清统计总数。
- `GuaranteeReshapesWaiting`：公开已知三项、统一宽度的未知中段问号与综合概率卡同屏。
- `UpIdentityLayer`：普通状态、非UP结果、下个五星保证UP三者同屏。
- `CapturingRadiance`：非保证五星的明光路径、两种统计范围、三轮“非UP→保证UP”时间线和下一次必触发分步出现。
- `StateMemoryConclusion`：第一层数字靠近五星判定，第二层规则靠近UP判定，完整路径同屏。

## v2 审阅反馈：曲线与数学层

- 问题：v1 主要使用数字卡、闸门和状态图。虽然出现了 `0.6%`、`0.447%`、`25.99%` 等数值，观众看不到条件概率、首次出金 PMF 和累计 CDF 随抽数怎样变化，也看不到三者如何由同一规则互相推导。
- 改进：v2 不再受约 4 分 40 秒长度限制，新增三条离散曲线、硬保底反事实模型、综合概率对平均等待的约束，以及 UP 等待双峰的卷积示意。
- 关键诊断：仅令第 1–89 抽保持 `0.6%`、第 90 抽强制出金时，平均等待约 `69.70` 抽，长期五星率约 `1.435%`；它达不到公开综合概率 `1.6%`。因此第 90 抽前某些位置必有额外抬升，但公开三数字不能唯一反推出具体逐抽曲线。
- 画面边界：不把根目录四张社区模型曲线直接贴进视频，也不把第 74 抽起线性增加的常见假设画成真实规则。v2 用三条等权、数值校准到同一平均等待的示意解展示“不唯一”。
- 双峰段只解释“小保底命中UP + 歪后进入大保底”下的混合分布和卷积；持续标明暂不计捕获明光、不是官方逐抽表。
